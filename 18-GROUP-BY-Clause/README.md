# 18 - GROUP BY Clause

## Objective

To learn how to group records using the `GROUP BY` clause and perform aggregate calculations for each group in the `Student` table.

## Task

Perform different grouping operations on the `Student` table.

The practical includes:

- Counting the number of students in each `class_id`.
- Finding the total age of students in each `class_id`.
- Finding the average age of students in each `class_id`.
- Counting students for each `class_id` and `address` combination.
- Counting students in each `class_id` who live in Kathmandu.

## SQL Concepts Learned

- `GROUP BY`
- `COUNT()`
- `SUM()`
- `AVG()`
- `WHERE`
- Column aliases using `AS`
- Grouping by multiple columns

## SQL File

The SQL implementation for this practical is available in [`lab18.sql`](lab18.sql).

## Result

The student records were successfully grouped according to `class_id` and `address`, and aggregate functions were used to calculate student counts, total ages, and average ages for each group.
