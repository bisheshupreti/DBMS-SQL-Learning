# 09 - Information Commands

## Objective

To use SQL information commands to view available databases, tables, and table structures.

## Task

Using the `company` database and the tables created in the previous practical:

- Display all available databases.
- Select the `company` database.
- Display all tables in the database.
- Display the structure of the `department` table using `DESC`.
- Display the complete table definition using `SHOW CREATE TABLE`.

## SQL Concepts Learned

- `SHOW DATABASES`
- `USE`
- `SHOW TABLES`
- `DESC`
- `SHOW CREATE TABLE`

## SQL File

The SQL implementation for this practical is available in [`lab09.sql`](lab09.sql).

## Result

The available databases, tables, and structure of the `department` table were successfully displayed using SQL information commands.
