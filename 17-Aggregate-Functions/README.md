# 17 - Aggregate Functions

## Objective

To learn how to perform calculations and summarize data from the `Student` table using SQL aggregate functions.

## Task

Perform different aggregate operations on the `Student` table.

The practical includes:

- Counting the total number of students.
- Counting students whose names end with `a`.
- Finding the total sum of all student ages.
- Finding the average age of all students.
- Finding the average age of students in `class_id` 4.
- Finding the maximum age among all students.
- Finding the minimum age of students living in Kathmandu.
- Counting the number of unique addresses.

## SQL Concepts Learned

- `COUNT()`
- `SUM()`
- `AVG()`
- `MAX()`
- `MIN()`
- `DISTINCT`
- `WHERE`
- Column aliases using `AS`
- Aggregate functions with conditional filtering

## SQL File

The SQL implementation for this practical is available in [`lab17.sql`](lab17.sql).

## Result

Different aggregate functions were successfully used to calculate and summarize data from the `Student` table, including the total number of students, sum and average of ages, maximum and minimum ages, and the number of unique addresses.
