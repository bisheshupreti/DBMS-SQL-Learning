# 26 - DELETE Statement

## Objective

To learn how to remove records from the `Student` table using the `DELETE` statement with specific conditions and subqueries.

## Task

Perform different DELETE operations on the `Student` table.

The practical includes:

- Deleting a specific student using `student_id`.
- Deleting all students whose age is greater than 20.
- Deleting students who belong to a specific class using a subquery.
- Displaying the student records before and after the DELETE operations.

## SQL Concepts Learned

- `DELETE`
- `WHERE`
- `IN`
- Subqueries
- Deleting records using `student_id`
- Deleting records based on `age`
- Deleting records based on another table

## SQL File

The SQL implementation for this practical is available in [`lab26.sql`](lab26.sql).

## Result

The required student records were successfully deleted using different conditions. The queries demonstrate deleting individual records, multiple records based on age, and records associated with a specific class using a subquery.
