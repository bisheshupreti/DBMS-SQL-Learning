# 11 - Complete College Database

## Objective

To create a complete college database with multiple tables, apply different constraints, and perform various table-altering operations.

## Task

Create a `college_management` database containing `Department` and `Student` tables with appropriate constraints.

The practical includes:

- Creating the `Department` table with primary key, unique, not-null, and check constraints.
- Creating the `Student` table with primary key, unique, foreign key, check, default, enum, and auto-increment properties.
- Adding, modifying, renaming, and dropping columns.
- Adding and removing constraints.
- Setting and removing default values.
- Displaying table structures using `DESC`.
- Displaying the complete table definition using `SHOW CREATE TABLE`.
