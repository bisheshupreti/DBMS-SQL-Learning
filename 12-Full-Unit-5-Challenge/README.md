# 12 - Full Unit 5 Challenge

## Objective

To apply the SQL concepts learned throughout Unit 5 by creating and modifying a database and tables using different data types, constraints, and table-altering operations.

## Task

Create an `ab_company` database with `department` and `employee` tables and perform various database and table operations.

The practical includes:

- Creating a database and tables.
- Using different SQL data types.
- Applying primary key, unique, check, foreign key, default, and not-null constraints.
- Displaying table structures.
- Displaying the complete table definition.
- Adding a new column.
- Modifying a column.
- Renaming a column.
- Adding and removing a constraint.
- Dropping a newly added column.
- Comparing `TRUNCATE` and `DROP`.
