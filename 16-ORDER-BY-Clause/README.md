# 16 - ORDER BY Clause

## Objective

To learn how to sort records from the `Student` table using the `ORDER BY` clause in ascending and descending order.

## Task

Perform different sorting operations on the `Student` table.

The practical includes:

- Displaying all students sorted by `student_id` in descending order.
- Displaying student names and ages sorted by age in ascending order.
- Displaying student names and ages sorted by age in descending order.
- Sorting students first by `class_id` and then alphabetically by name.
- Displaying students older than 20 and sorting them alphabetically by name.

## SQL Concepts Learned

- `ORDER BY`
- Ascending Order: `ASC`
- Descending Order: `DESC`
- Multiple-column sorting
- Combining `WHERE` with `ORDER BY`
- Default sorting order of `ORDER BY`

## SQL File

The SQL implementation for this practical is available in [`lab16.sql`](lab16.sql).

## Result

The student records were successfully sorted using `ORDER BY` in both ascending and descending order. Multiple columns were also used to perform sequential sorting, and `WHERE` was combined with `ORDER BY` to filter and sort records.
