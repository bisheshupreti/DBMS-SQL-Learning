# 21 - LEFT JOIN and RIGHT JOIN

## Objective

To learn how to retrieve related data from the `Student` and `Class` tables using `LEFT JOIN` and `RIGHT JOIN`.

## Task

Perform different LEFT JOIN and RIGHT JOIN operations using the `Student` and `Class` tables.

The practical includes:

- Displaying all students and their class names using `LEFT JOIN`.
- Displaying all classes and their students using `RIGHT JOIN`.
- Displaying students older than 18 and their class names using `LEFT JOIN`.

## SQL Concepts Learned

- `LEFT JOIN`
- `RIGHT JOIN`
- `ON`
- Table Aliases
- `WHERE`
- Joining tables using related columns

## SQL File

The SQL implementation for this practical is available in [`lab21.sql`](lab21.sql).

## Result

The `Student` and `Class` tables were successfully joined using both `LEFT JOIN` and `RIGHT JOIN`. The queries retrieved student and class information, including students older than 18 using a filtering condition.
