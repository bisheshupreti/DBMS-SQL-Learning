# 01 - Database and Basic Table

## Objective

To create a database named `college` and create a `student` table with the required fields.

## Tasks

- Create a database named `college`.
- Select the `college` database.
- Create a `student` table with the following fields:
  - `student_id` — INT, Primary Key, Auto Increment
  - `name` — VARCHAR(50), NOT NULL
  - `age` — INT
  - `address` — VARCHAR(100)
- Display the structure of the `student` table using `DESC`.

## SQL Concepts Learned

- `CREATE DATABASE`
- `USE`
- `CREATE TABLE`
- `PRIMARY KEY`
- `AUTO_INCREMENT`
- `NOT NULL`
- `DESC`

The `college` database and `student` table were created successfully, and the table structure was displayed using `DESC`.
