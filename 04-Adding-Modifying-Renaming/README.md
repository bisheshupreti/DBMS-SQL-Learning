# 04 - Adding, Modifying and Renaming

## Objective

To practice adding, modifying, renaming, and dropping columns and renaming a table using `ALTER TABLE` and `RENAME TABLE`.

## Task

Create a `student` table and perform the following operations:

- Add a new `email` column.
- Modify the `email` column.
- Rename `email` to `student_email`.
- Add a `phone` column.
- Drop the `phone` column.
- Rename the `student` table to `students`.
- Display the final table structure using `DESC`.

## SQL Concepts Learned

- `ALTER TABLE`
- `ADD COLUMN`
- `MODIFY COLUMN`
- `RENAME COLUMN`
- `DROP COLUMN`
- `RENAME TABLE`
- `DESC`

## SQL File

The SQL implementation for this practical is available in [`lab04.sql`](lab04.sql).

## Result

The table was successfully modified by adding, modifying, renaming, and dropping columns, and the table was renamed from `student` to `students`.
