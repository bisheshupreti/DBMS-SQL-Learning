# 02 - Data Types

## Objective

To create an `employee` table using appropriate SQL data types for different types of data.

## Task

Create an `employee` table using the following data types appropriately:

- `INT` for Employee ID
- `VARCHAR` for Employee Name
- `DECIMAL` for Salary
- `DATE` for Date of Birth
- `ENUM` for Gender
- `BOOLEAN` for Active Status
- `TIMESTAMP` for Created Date & Time

## SQL Concepts Learned

- `INT` — Used for integer values such as employee ID.
- `VARCHAR` — Used for variable-length text such as employee name.
- `DECIMAL` — Used for precise numeric values such as salary.
- `DATE` — Used for calendar dates such as date of birth.
- `ENUM` — Used for a predefined set of values such as gender.
- `BOOLEAN` — Used for TRUE/FALSE values such as active status.
- `TIMESTAMP` — Used for date and time values.
