# 22 - CROSS JOIN

## Objective

To learn how to generate all possible combinations of records from the `Student` and `Class` tables using the `CROSS JOIN`.

## Task

Perform different CROSS JOIN operations using the `Student` and `Class` tables.

The practical includes:

- Displaying all possible combinations of student names and class names.
- Displaying possible student and class combinations for students older than 20.

## SQL Concepts Learned

- `CROSS JOIN`
- Cartesian Product
- Table Aliases
- `WHERE`
- Filtering CROSS JOIN results

## SQL File

The SQL implementation for this practical is available in [`lab22.sql`](lab22.sql).

## Result

All possible combinations of student names and class names were successfully generated using `CROSS JOIN`. The second query filtered the combinations to include only students whose age is greater than 20.
