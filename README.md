# DBMS & SQL Learning Repository

A practical learning repository for **Database Management System (DBMS)** and **SQL**, documenting my practical work, exercises, implementations, and learning throughout the course.

This repository is maintained as a long-term learning record rather than only a collection of submitted lab reports.

---

## About the Course

**Course:** Database Management System
**Course Code:** CACS255

The course provides theoretical and practical knowledge of database management systems, including database design, relational models, SQL, data manipulation, stored procedures, triggers, indexing, query processing, security, transactions, and concurrency control.

---

## Course Objectives

The practical work in this repository supports the major objectives of the course:

* Understanding the basic concepts and theories of DBMS
* Learning database design and implementation
* Working with relational databases
* Using SQL commands for handling data and transactions
* Applying DBMS concepts through practical implementation
