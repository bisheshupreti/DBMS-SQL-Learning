# Lab 32 – Triggers — UPDATE (BEFORE and AFTER)

## Objective

To learn how to use BEFORE UPDATE and AFTER UPDATE triggers on the `Employee` table to prevent unauthorized salary decreases and maintain a salary audit record.

## Tasks

The following trigger operations were performed:

1. Created a BEFORE UPDATE trigger `trg_before_update_salary` on the `Employee` table.
2. Configured the trigger to prevent salary decreases using `SIGNAL SQLSTATE '45000'`.
3. Attempted to decrease the salary of employee ID `1` and observed the error generated by the trigger.
4. Created an AFTER UPDATE trigger `trg_after_update_salary` to record old and new salary values in the `Salary_Audit` table.
5. Increased the salary of employee ID `1` and verified the salary audit record.
6. Displayed the contents of the `Salary_Audit` table.
7. Updated the salaries of all employees by 10% and verified that multiple audit records were generated.
8. Displayed all triggers using `SHOW TRIGGERS`.

## SQL Concepts Learned

* Creating BEFORE UPDATE triggers
* Creating AFTER UPDATE triggers
* Using `OLD` and `NEW` values in triggers
* Using `SIGNAL SQLSTATE` to generate custom errors
* Preventing unwanted data modifications
* Maintaining an audit trail using triggers
* Performing multi-row UPDATE operations
* Verifying trigger-generated audit records
* Viewing triggers using `SHOW TRIGGERS`
