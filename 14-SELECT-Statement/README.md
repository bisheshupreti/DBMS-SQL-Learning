# 14 - SELECT Statement

## Objective

To learn the basic use of the `SELECT` statement for retrieving data from the `Student` table.

## Task

Perform basic data retrieval operations on the `Student` table.

The practical includes:

- Displaying all columns and rows.
- Displaying only the `name` and `age` columns.
- Displaying unique addresses using `DISTINCT`.
- Renaming columns using aliases.
- Displaying only the first three records using `LIMIT`.

## SQL Concepts Learned

- `SELECT`
- `FROM`
- `DISTINCT`
- Column Aliases using `AS`
- `LIMIT`

## SQL File

The SQL implementation for this practical is available in [`lab14.sql`](lab14.sql).

## Result

The required student records were successfully retrieved using different `SELECT` statement operations, including filtering unique values, assigning column aliases, and limiting the number of returned rows.
