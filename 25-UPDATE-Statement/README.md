# 25 - UPDATE Statement

## Objective

To learn how to modify existing records in the `Student` table using the `UPDATE` statement with different conditions and subqueries.

## Task

Perform different UPDATE operations on the `Student` table.

The practical includes:

- Updating the age of a specific student using `student_id`.
- Increasing the age of all students in a specific `class_id` by 1.
- Updating the address of students based on their class name using a subquery.
- Updating the `class_id` of students whose age is greater than 22.

## SQL Concepts Learned

- `UPDATE`
- `SET`
- `WHERE`
- Arithmetic Expressions
- Subqueries
- `IN`
- Updating records using `student_id`
- Updating records based on `class_id`
- Updating records based on another table

## SQL File

The SQL implementation for this practical is available in [`lab25.sql`](lab25.sql).

## Result

The required student records were successfully updated using different conditions. The queries demonstrate updating individual records, modifying multiple records, and using a subquery to update student addresses based on class information.
